NYC Taxi Lakehouse

University · individualNYC taxi trips, taken from a public source into a data lake and made queryable on several platforms.MinIO · Apache Iceberg · ClickHouse · dlt+
The problem
Large public datasets have to be loaded, stored and checked in a repeatable way before anyone can query them with confidence.
What I built
A university project I built end to end: a lakehouse pipeline that downloads the NYC Yellow Taxi data, stores it as Parquet in MinIO, registers Apache Iceberg tables in a Nessie catalogue and distributes them to Azure ADLS and ClickHouse with dlt, processing in PyArrow batches.

Evidence and context

  • Individual university project.
  • 3,475,226 rows validated across the pipeline stages.
  • A verification script for each stage; runs locally with Docker Compose.

SaludRed

University · individualOne shared, up-to-date view of hospital beds, requests and priorities across a care network.FastAPI · PostgreSQL · HL7 FHIR R4 · Docker+
The problem
A bed can be physically free and still go unused if nobody knows its status in time. Fragmented updates lead to waiting patients, repeated calls and no record of who changed what.
What I built
A university project I built end to end: a FastAPI and PostgreSQL system for an EPS/IPS network, with a bed queue ordered by clinical priority, audited assignments, role-based access, account lockout, network analytics with k-means patient clustering implemented from scratch, LOINC-validated vital signs, an HL7 FHIR R4 integration and a role-based web interface.

Evidence and context

  • Individual university project with synthetic data only, from a deterministic generator with clinical profiles and a bed simulation running near 85% occupancy.
  • Bed queue ordered by clinical priority, then waiting time; skipping it requires a reason that is logged in the audit trail.
  • Analytics: median and 90th-percentile waits, bed turnaround and a recommendation of which IPS should take the next patient.
  • A pytest suite with 120+ tests. A functional academic prototype, not a system in clinical use.
